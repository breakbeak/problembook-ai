# 📚 AI 문제집 — 휴대폰 배포용 최종 패키지

관리자 페이지와 사용자 사이트가 하나의 Flask 서버에 들어 있습니다.

- 관리자: `/admin`
- 사용자: `/`
- 관리자 API 키 저장/연결 테스트
- 관리자 사용자 계정 생성
- 친구 로그인
- 갤러리/카메라 사진
- PDF / TXT / MD / CSV / DOCX / PPTX / XLSX
- AI 문제 요약/정답/풀이/힌트/유사문제

## 배포
`DEPLOY_PHONE.md`를 먼저 읽어주세요.

Render용 `render.yaml`도 포함되어 있어 휴대폰에서 GitHub 저장소를 연결해 배포하기 쉽게 해두었습니다.

**중요:** ZIP 파일을 Chrome에서 `content://...`로 열면 서버가 실행되지 않습니다.
반드시 실제 웹 서버에 배포한 뒤 `https://...` 주소로 접속해야 합니다.
